# 天の声 Bot (Tennokoe Bot) - Go版

Discord通話間で音声を転送するためのボットシステムです。一つの通話（通話A）の音声を別の通話（通話B）にリアルタイムで転送します。

## 機能

- 通話Aに参加して音声をリッスンするBot
- 通話Bに参加して音声を再生するBot
- 両方のBotを連携させて音声をリアルタイムで転送
- `heaven!speak`コマンドを使用して、コマンドを送信したユーザーのボイスチャンネルに自動接続する機能
- `heaven!listen`コマンドを使用して、コマンドを送信したユーザーのボイスチャンネルに自動接続する機能
- 両方のBotが同じボイスチャンネルに接続されることを防止する機能

## 必要条件

- Go 1.16以上
- 2つのDiscord Botアカウント（トークン）

## インストール方法

1. リポジトリをクローンまたはダウンロードします
```
git clone https://github.com/yourusername/tennokoe-bot.git
cd tennokoe-bot
```

2. 依存関係をインストールします（Goがインストールされている場合）
```
go mod download
```

3. `.env`ファイルを設定します
```
# リスニング用ボットのトークン
LISTENING_BOT_TOKEN=あなたのリスニングボットトークンをここに入力

# スピーキング用ボットのトークン
SPEAKING_BOT_TOKEN=あなたのスピーキングボットトークンをここに入力
```

## 使い方

1. プログラムを起動します
```
./tennokoe-bot
```
Windowsの場合:
```
tennokoe-bot.exe
```

2. テキストチャンネルで`heaven!listen`コマンドを送信すると、リスニングBotがそのコマンドを送信したユーザーが参加しているボイスチャンネルに自動的に接続します
3. 別のテキストチャンネルまたは同じテキストチャンネルで`heaven!speak`コマンドを送信すると、スピーキングBotがそのコマンドを送信したユーザーが参加しているボイスチャンネルに自動的に接続します
4. 通話Aでの会話が通話Bに転送されます

注意: 両方のBotが同じボイスチャンネルに接続されることはできません。同じチャンネルでコマンドを実行しようとするとエラーメッセージが表示されます。

## インポートパスについて

このプロジェクトでは、ローカルモジュールのインポートパスとして `tennokoe-bot/internal/...` の形式を使用しています。これは、Goのモジュールシステムの慣習に従ったものです。

実際の開発では、以下のいずれかの方法を選択できます：

1. **ローカルモジュール**: 現在の実装のように `tennokoe-bot/...` を使用
2. **公開予定のモジュール**: `github.com/yourusername/tennokoe-bot/...` のようなリポジトリURLを使用
3. **架空ドメイン**: `example.com/tennokoe-bot/...` のような架空のドメインを使用

インポートパスを変更する場合は、go.modファイルのモジュールパスと、すべてのソースファイル内のインポート文を一貫して更新する必要があります。

## 仕組み

1. リスニングBot: 通話Aに参加し、ユーザーの音声を受信します
2. 受信した音声データはメモリ内のバッファと一時ファイルに保存されます
3. スピーキングBot: 通話Bに参加し、音声データを受信して再生します
4. 両方のBotは共有の音声プロセッサを通じてデータを交換します

## 注意事項

- このプロジェクトはプロトタイプであり、実際の使用には最適化が必要な場合があります
- 音声の転送には若干の遅延が発生する可能性があります
- 大量のユーザーが同時に話すと、音声が混ざる可能性があります
- Discord APIの利用規約に従って使用してください

## Discord Botの作成方法

1. [Discord Developer Portal](https://discord.com/developers/applications)にアクセスします
2. 「New Application」をクリックして2つのアプリケーションを作成します
3. 各アプリケーションの「Bot」タブでボットを有効化します
4. 「Reset Token」をクリックしてトークンを取得し、`.env`ファイルに設定します
5. 「Privileged Gateway Intents」セクションで以下を有効化します:
   - SERVER MEMBERS INTENT
   - MESSAGE CONTENT INTENT
   - VOICE STATE INTENT
6. 「OAuth2」→「URL Generator」で必要な権限を選択してボットを招待するURLを生成します:
   - `bot` スコープ
   - 権限: `Connect`, `Speak`, `Use Voice Activity`

## トラブルシューティング

- **ボットが接続できない**: トークンが正しいか確認してください
- **音声が転送されない**: ボットが正しいチャンネルに接続されているか確認してください
- **エラーが発生する**: Goのバージョンが1.16以上であることを確認してください
